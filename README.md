# Personal Programming Archive

A personal collection of programming practice, exercises, experiments, and learning materials collected throughout my early programming journey.

This repository contains code and materials created while learning programming through **PIAIC coursework, online tutorials and videos, self-learning, and university studies**.

## About

Most of the material in this repository was created between **2021 and 2023**, primarily before starting university. It represents my early exploration of programming and the process of building a foundation in different programming concepts and technologies.

The repository also contains some material created later during my university years as I continued practicing, revisiting concepts, and experimenting with different approaches.

## Sources of Learning

The material comes from several stages and sources of my learning:

* **PIAIC (Presidential Initiative for Artificial Intelligence and Computing)** coursework and practice
* Online programming tutorials and video courses
* Self-learning and experimentation
* Programming exercises and practice problems
* University-related learning and practice
* Personal experiments and small programs

Some implementations may have been created by following tutorials or learning resources, while others were written independently as part of practicing and understanding the concepts.

## Contents

The repository contains a variety of programming-related material, including:

* Programming fundamentals
* Practice exercises and problems
* Small programs and experiments
* Learning exercises from tutorials and courses
* PIAIC coursework and practice
* University-related programming work
* Notes and supporting learning material
* Experiments with different programming concepts and technologies
* Older code from my early programming journey

## Purpose

This repository is primarily a **personal learning archive and historical record of my programming journey**.

It is maintained on GitHub to preserve the work I created while learning programming and to document how my skills and interests developed over time.

The code is not intended to represent production-ready software. Some projects may be incomplete, experimental, repetitive, or written specifically to understand a particular concept.

## Note

This repository contains work from different stages of my learning. Code quality, structure, and complexity may vary significantly between directories and projects.

Some projects in this repository, particularly **web development projects**, have been moved to or are also maintained in their **own dedicated repositories** on my GitHub profile. This repository primarily serves as an archive of the learning material and original practice work.

Older material is preserved intentionally as part of the progression of my programming experience rather than being rewritten or removed.
